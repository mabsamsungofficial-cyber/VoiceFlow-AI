# 🎙️ VoiceFlow AI

> Ultra-Fast Cross-Platform Voice Dictation & AI Prompt Companion inspired by Wispr Flow.  
> Supporting Roman Hinglish, Hindi, and English with auto speech-filler stripping.

---

## 🌟 Platforms & Releases

| Platform | Location | Current Track | Features |
| :--- | :--- | :--- | :--- |
| **Android Companion** | [`android/`](file:///android/) | **`v3.3.0`** | In-Field Auto-Typing, Hold-to-Talk (PTT), WhatsApp Whitelist, Magnetic Docking |
| **Windows Desktop** | [`windows/`](file:///windows/) | **`v2.1.0`** | Global Hotkeys (`Ctrl+Shift+Space`), Auto-Paste SendKeys, System Tray |
| **Web Dashboard** | [`src/`](file:///src/) | **`v3.3.0`** | Modern Obsidian Glass UI, Prompt Engineer Mode, History Drawer |

---

## 🚀 One-Click Commands

```bash
# 🌐 Web Dashboard (Dev Mode)
npm run dev:web

# 💻 Windows Desktop (Electron with Hotkeys)
npm run start:windows

# 📱 Android: Sync assets and compile APK
npm run build:android
npm run build:apk

# 📦 All-in-One: Build Web + Sync Android + Compile APK
npm run build:all
```
