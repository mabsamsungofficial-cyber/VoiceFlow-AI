============================================================================
VOICEFLOW v2.0 - SMART HINGLISH VOICE-TO-TEXT ENGINE
(Android System-Wide Floating Mic & Windows Global Hotkey)
============================================================================

MERA GOAL / KYA KAAM KARTA HAI:
1. Natural Boliye: Natural Hindi / Hinglish me bolein.
2. Zero Fillers: "uh", "um", "aa", background noise AI filter out kar deta hai.
3. Self-Correction: Bolte waqt baat badal li ("kal 4 baje nahi shaam 6 baje"), toh AI aakhri sahi baat likhega.
4. Hinglish Script (WhatsApp / Messages ke liye): Roman English letters me ready-to-paste text.
5. AI Prompt Converter: History me kisi bhi draft ko 1 click me professional AI Prompt me convert karein!

----------------------------------------------------------------------------
PLATFORM 1: WINDOWS DESKTOP APP (GLOBAL HOTKEY & DIRECT AUTO-PASTE)
----------------------------------------------------------------------------
Kahin bhi kisi bhi app me (Chrome, Notepad, VS Code, WhatsApp Desktop, Word):
1. Terminal me run karein:
   npm run start:windows
2. Kahin bhi kisi text field me cursor rakhein aur shortcut dabayein:
   [ Ctrl + Shift + Space ]  ya  [ Alt + V ]
3. VoiceFlow ka mic pop-up aayega -> Boliye -> jaise hi bolein khatam hoga:
   AI turant Hinglish text ko directly usi input field me type / paste kar dega!
   Aapko manually keyboard se paste bhi nahi karna padega.

----------------------------------------------------------------------------
PLATFORM 2: ANDROID SYSTEM-WIDE FLOATING MIC (DUSRE APPS KE UPAR)
----------------------------------------------------------------------------
App open karne ki zaroorat nahi:
1. App khol kar Settings me "Floating mic overlay" ON karein.
2. Android aapse "Display over other apps" permission mangega -> Allow karein.
3. Ek glowing floating mic button aapke phone ki screen par WhatsApp, Instagram,
   Chrome, Notes har app ke upar float karega!
4. Kahin bhi tap karke boliye -> Text turant copy ho jayega!

----------------------------------------------------------------------------
APK KAISE BANAYEIN (GitHub Actions se 3 minute me):
----------------------------------------------------------------------------
1. github.com par login karein -> "New repository" banayein.
2. Is folder ka sara content upload karein (.github aur android folder samet).
3. GitHub me "Actions" tab par jayein -> "Build APK" chalega.
4. "Artifacts" me se "VoiceFlow-v2-APK" download karein -> phone me install karein.
